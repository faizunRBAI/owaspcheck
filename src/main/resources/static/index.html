API surface

All catalog endpoints require a bearer token. Obtain one from POST /api/v1/auth/login, then send Authorization: Bearer <token>.

MethodPathPurpose
POST/api/v1/auth/registerCreate a user, receive a JWT
POST/api/v1/auth/loginExchange credentials for a JWT
GET/api/v1/projectsList projects (filter by teamId)
POST/api/v1/projectsCreate a project
PUT/api/v1/projects/{id}Update a project
DELETE/api/v1/projects/{id}Delete a project
GET/api/v1/teamsList teams
GET/api/v1/environmentsList environments (filter by projectId)
GET/api/v1/deploymentsList deployments (filter by environmentId)
